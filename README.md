# Optimizer Agent

A library to auto optimize and discover things with an LLM agent.

## Getting started:


1. Installation
```bash
python3 -m venv env_optagent
source env_optagent/bin/activate

pip3 install -e .
```

2. Running example:
```bash
# ./examples/test_example/run.sh
./examples/cuda_engineering/run.sh
```
